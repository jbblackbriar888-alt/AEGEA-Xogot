# Основа и происхождение

Исходный архив: `AEGEA-5.6.zip`.

SHA-256 исходного ZIP:

`910388378889cdb5e67d2a833954cd49572a7082c1ebacab8e0cbc267943a1ca`

В `data/catalog.json` перенесены определения ресурсов, предметов, экипировки, 28 зданий, рецептов, островов, кораблей и приказов из 5.6. `data/initial_world.json` — исходный новый мир 5.6, включая данные морских животных. Личное сохранение игры в Safari не извлекалось.

77 GLB взяты из мобильного набора исходной сборки, 28 JPG — из меню согласованных построек, 26 MP3 — из мобильного звука. Модели не заменялись случайными похожими зданиями. В Godot меняются масштаб экземпляра, материалы отдельных парусов и способы отрисовки, но исходные GLB сохранены. Для козы исправлено применение крайне малого исходного масштаба при инстанцировании.

Значки инвентаря — SVG из `src/item-art.js` исходной игры. Удалён только SVG-фильтр тени, несовместимый с частью импортёров. Это собственные рисунки AEGEA, не графика Lineage 2M. Снимки Lineage не являются игровыми ассетами и в эту сборку не включены.

`tools/asset-pipeline/` и тестовые fixtures не включены в эту поставку для телефона. `data/architecture-approved.json` и `data/architecture-sources.json` содержат согласованные варианты и происхождение архитектуры.

Лицензии исходных ассетов сохранены в `ASSET-LICENSES.md` и `licenses/`. Лицензия шрифта DejaVu — `assets/FONT-LICENSE.txt`. Документ ASSET-LICENSES содержит историю браузерных версий; упоминания Three.js/Web Audio описывают происхождение, не используемый здесь движок. Сам Three.js не запускается и не нужен проекту. Его уведомление сохранено для происхождения ранее использованных материалов.

Новые GDScript-системы, нативные сцены и Godot-шейдеры написаны специально для переноса. Архив не включает исполняемый файл Godot, не содержит C#, GDExtension, токенов Vercel или подключений к внешнему серверу.
